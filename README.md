# Quantum Zeno Effect - Semester Project

**Status:** Work in progress  
**University:** Warsaw University of Technology, Faculty of Physics  
**Coursework:** Assessed Engineering Physics semester project (replacing one course test)  
**Students:** Adam Kubica and Szymon Jędryka

## About the project

We are working together on a numerical project about the **quantum Zeno effect**. We want to explore how repeatedly measuring a quantum system can influence its evolution over time.

This is a university semester project, not a completed research paper.

## What we plan to investigate

- How the probability of remaining in the initial quantum state changes with the number of measurements.
- How to represent the evolution of a simple quantum system mathematically.
- Whether the numerical results agree with the predictions of the model we eventually choose.
- How to check our calculations and present the results clearly.

## Planned tools

We plan to use **Python** and **NumPy** for numerical calculations, and **Matplotlib** for graphs. The specific physical model and computational approach are still being worked out.

## Current progress

The project is **in progress**. This repository currently contains only the topic and our planned direction. We have **not** published completed simulation code, results or conclusions.
